# Assets de la UI

Poner aquí el logo de la empresa como **`logo.png`** (fondo transparente, alto
~120 px). `estilos.ruta_logo()` lo detecta solo y lo muestra en la barra
lateral con `st.logo`; si el archivo no está, la app arranca igual, sin logo.

Al subirlo hay que **committearlo**: en Streamlit Community Cloud la app solo
tiene lo que esté en el repositorio.
